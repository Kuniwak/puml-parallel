# Contributing

## Triaging requests

Maintainers weigh a feature request or a proposal by these principles, in this order:

1. **Consistency**: the tools and their notations work alike; a change does not set one part apart from the rest.
2. **Maintainability**: a change keeps the code small and its parts independent.
3. **Functionality**: what the change lets a user do.

If a problem can be solved by combining existing features, of these tools or of other tools, it is solved that way rather than by a new feature (the Unix philosophy). A request declined on this ground is answered with the combination that solves it.
